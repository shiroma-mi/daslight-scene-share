# Daslight Scene Share

Daslight 5のシーン・バンク・スーパーシーンをPC間で共有する非公式ツールです。
ブラウザー内で処理し、選択したプロジェクトや音源をサーバーへ送信しません。

## 使い方

1. 取り込み元の `.dvc` または `.dlshare` を選びます。
2. 共有するシーンを選択します。スーパーシーンの参照先は自動で含まれます。
3. 共有だけなら `.dlshare` を書き出します。
4. 統合する場合は取り込み先 `.dvc` を選び、灯体の対応を確認して保存します。
5. 出力した `.dvc` をDaslightの「開く」で読み込み、保存・再読込・再生を確認してください。

既存データを上書きせず、新しいバンクとして追加します。繰り返し取り込むと別のコピーが増えます。
共有ファイルには選択シーン・依存シーンと、元の全灯体パッチ・グループを含めます。
音源・画像本体は別途共有し、取り込み先でのパスを指定してください。

## 対応範囲と検証状況

- 解析・本体保存検証：Daslight 5 build 25.0905.165.111 / VERSIONFILE 2。
- 同一ビルド間で使用してください。
- 同じチャンネル定義・プリセット・ビーム構成の灯体を対応付けます。異なるDMXアドレスにも手動で割り当てられます。
- 灯体が不足する場合、元アドレスが空いていれば追加できます。
- 異機種・異モード変換、特殊マトリクス灯体、複数モードを含む未解析形式、ジャンプ設定は対応外です。
- 取り込み元のTouch・MIDI等の割り当ては移行しません。
- 変換エンジンの自動テスト20項目を通過。MacのDaslightで読込・保存・再読込を確認。
- 公開版のChromeで、.dvc読込、選択、統合ファイルの保存、.dlshare書出しと再読込を確認しました。保存されたファイルの灯体値とパッチの保持も検証済みです。
- Windowsと実機DMX出力は未検証です。
- 欠落音源のある状態でDaslightに保存すると音源ブロックのBPM属性が失われるケースを確認しています。音源を再リンクしテンポ同期を確認してください。

## ローカル利用

`index.html` を対応するChrome / Edgeで開けます。外部依存やビルド工程はありません。

## GitHub Pages

公開リポジトリの `main` ブランチのルートに配置し、Settings → Pages → Deploy from a branch → main / (root) を選択します。
プロジェクト `.dvc`、共有データ `.dlshare`、音源、個人用の検証資料は公開しないでください。
