つくった光を、次のPCへ。

シーン・バンク・スーパーシーンをまとめて共有。灯体の対応を確認して、Daslight 5で開けるプロジェクトを書き出します。ファイルはこのPC内で処理します。

1共有するデータを開く

.dvc または、このアプリの共有ファイル .dlshare

2取り込み先を開く

共有ファイルを書き出すだけなら、選択は不要です。

3共有するシーンを選ぶ

バンク名のチェックで一括選択。スーパーシーンに必要なシーンも自動で含めます。

取り込み元ファイルを開くと、シーンが表示されます。

ファイルを選択してください。
自動で含まれるシーン

灯体の対応

同じ内部ID、または同じチャンネル定義・DMXアドレスで候補を選びます。アドレスが違うときは、右側で対応する灯体を指定してください。

取り込み元の灯体取り込み先の灯体

同じチャンネル数だけでは一致と判定しません。チャンネル定義・プリセット・ビームが一致する灯体のみ選択できます。追加する灯体は元のDMXアドレスを使います。

音源・画像の場所

これらのファイル本体は .dvc に含まれていません。別途コピーし、取り込み先PCでの絶対パスを入力してください。空欄なら元のパスを維持します。パスの存在はこのアプリでは確認できません。

共有・保存

既存データは上書きせず、新しいバンクとして追加します。
共有ファイルには選択したシーン・依存シーンと、元の全灯体パッチ・グループを含めます。

使い方と対応範囲

送る人：元の .dvc を開く → シーンを選択 → 「共有ファイルを書き出す」。受け取る人：.dlshare と統合先 .dvc を開く → 灯体の対応を確認 → 「統合した .dvc を保存」。2つの .dvc を直接統合することもできます。

書き出した .dvc は Daslight の「開く」で開き、別名保存してから再度開いて確認してください。「シーンのインポート」は使いません。繰り返し取り込むと別のコピーが増えます。

対応：通常シーン、ステップ、FXの灯体参照、バンク属性、スーパーシーンの依存関係・タイミング・オートメーション。取り込み先の既存パッチ・シーン・Touch・ショートカットを維持します。元側のTouch・MIDI等の割り当ては取り込みません。

異なるモード間のチャンネル変換、特殊マトリクス灯体、複数モードを含む未解析形式、ジャンプ設定は対応外です。不明な参照や不整合を検出した場合は保存を止めます。音源・画像本体は別途共有してください。

解析対象：Daslight 5 / VERSIONFILE 2 / build 25.0905.165.111。同一ビルド間のみ統合します。ブラウザーはCompressionStream / DecompressionStream対応が必要です。
